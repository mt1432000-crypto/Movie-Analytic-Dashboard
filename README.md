# 🎬 Movie Analytics Dashboard

An interactive Power BI dashboard built to analyze movie data, trends, ratings, and financial performances. This project explores deep insights into cinematic data using a clean **Dark Mode** aesthetic.

---

## 🚀 Project Overview
This dashboard helps in exploring various aspects of the movie industry, such as top-rated genres, revenue vs. budget analysis, director performance, and release trends over the years.

---

## 🛠️ Tools & Techniques Used
- **Power BI:** For creating interactive data visualizations and measure cards.
- **Power Query:** For data cleaning, transformation, and ETL processes.
- **DAX Measures:** For calculating metrics, aggregations, and dynamic KPIs.
- **Star Schema Modeling:** Ensuring optimized data relationships and performance.
